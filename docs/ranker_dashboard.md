# Ranker 线上看板

内部 wiki 摘录（2026-08 看板任务 `ranker.dashboard.prod`）。离线实验如果要对齐线上，以这里为准。

## 覆盖与延迟

- 覆盖：有曝光且候选数 ≥ 2 的 request。
- 延迟：排序 RT p99 单独看，不进效果看板。
- 抽样：全量 request，不做 session 加权抽样。

## 主效果指标：GAUC

任务名 `ranker.gauc.serving`。

1. 标签是点击 0/1，不是互动深度。
2. 每个 request 内部算一次 ROC-AUC。
3. 只有单一标签的 request 跳过（AUC 无定义）。
4. 最终数字是 request 等权平均。不要按点击数加权，也不要按互动分加权。

## 辅助指标

- NDCG@1 / NDCG@3：列表截断后的排序质量。
- 曝光覆盖率、空结果率：服务可用性，不是效果。

## 和离线实验

看板口径变更要单独发评审。离线脚本可以先看自己的报表，但上线结论必须能在这个看板上复现。
